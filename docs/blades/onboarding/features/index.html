Every hull carries a systems register; this is the board’s — and whether you already fly with the Blades or you’re sizing us up from outside, it’s the honest manifest of what we’ve built and where we’re headed. One purpose behind all of it: put the whole squadron’s effort on a single pane of glass — what we’re building, what it’s starving for, where to buy it, and whose name goes on the plaque. Read the lamps: steady green is flight-proven kit, steady amber is fitted and awaiting shakedown, and the breathing violet is still on the drawing board — it glows because we intend it, it fades because it isn’t real yet.

What the Onyx Blades toolset does — for members and anyone weighing up joining. The Blades run a live site for Elite Dangerous that tracks colonisation builds end-to-end (live progress, supplier sourcing, automatic build registration, architect attribution, and per-commander stats), with more game loops on the way. Status lamps: green = verified working, amber = built, awaiting live test, pulsing violet = planned / not built yet.

01
The Flight Deck
What every pilot flies · flight-proven
Closed-Net Access
The board rides a sealed channel — Onyx Blades eyes only. Every page, every download, gated at the perimeter.Cloudflare Access gates every /blades page and the plugin download. Squad emails only, one-time PIN login.
Live Colonisation Board
The wired build on one screen: completion, outstanding tonnage, and how many bellies-full it takes your current ship to finish the job.Live build progress from RavenColonial: % complete, remaining tonnage per commodity, and trip-count math keyed to your live loadout.
Loadout-Aware Trip Counter
The board counts trips in YOUR hull, not a stranger's — swap into a bigger belly and the run-count drops the moment you dock.Trip math uses your live ship's cargo capacity (reported by the plugin), not a fixed Type-9. Recomputes automatically when you swap ships.
Live Ship & Cargo Report
The wing sees what you're flying and how much you can carry, without you saying a word.The Blades Registrar plugin reports your current ship, hold size and used space to the board (MY STATS current-ship readout + SQUAD HAULERS panel). Newest report wins.
Supplier Targeting
Tap any commodity and the nav computer ranks nearby markets that actually have it — Large pads first, carriers flagged as the moving targets they are. ⧉ beams the system straight to your clipboard.Per-commodity supplier rankings via the Ardent network: in-stock and Large-pad gated, distance/price scored, fleet carriers and stale data flagged. One-click system-name copy.
Manifest Sort Cycle
The manifest sorts to the job in hand — heaviest need first to triage the haul, A–Z to match the pad, or grouped by market class the way the commodities board reads. One tap cycles it; the deck remembers.A ↕ SORT button on the shipping manifest cycles highest-need → A–Z → market-category grouping and remembers the choice. Category grouping awaiting an in-game cross-check.
Commodity Name Resolver
Every cargo reads true — no more run-together gibberish where the game's shorthand meets the board. The name you see is the name Inara knows.Manifest commodity names resolve through a normalised index of the full commodity table (plus Elite's internal-symbol quirks), so run-together names display correctly and their ↗ Inara links land on the right commodity.
Inara Supplier Cross-Check
A second set of eyes on the trade lanes — one tap opens Inara's ledger for the same cargo, near the same build, when you want to double-check the fleet's own numbers.Each commodity supplier drawer carries an ↗ Inara deep-link to that commodity's sellers near the build system (also shown when Ardent finds nothing or is unreachable). Link-out only — Inara exposes no live market API. Awaiting an active build to verify in the drawer.
Transmit-from-Inara
Chase a supplier on Inara, copy the system, and one glowing button beams it to your cockpit PC — then it's gone, its work done.After an Inara supplier look-up, a ⧉ TRANSMIT SYSTEM → PC button reads the copied system from your clipboard and sends it to your PC via the plugin, then clears itself once sent (and times out on its own if unused). Verified.
SQUAD NET Ticker
The wire that never sleeps — build status, most-needed cargo, commander syncs, carrier movements. Rides every console; goes loud when a window is closing.Scrolling status line on every page (Home · Colonisation · My Stats): build %, most-needed commodity, per-commander hauls, linked carriers. Alert tiers escalate when a build deadline nears.
Cockpit Fittings
Four hull liveries on a rotary dial, a galactic⇄local chronometer, and this very SIGNAL toggle. The ship remembers how you like it.Theme dial (amber / cyan / onyx / jade-green), ED⇄local clock, lore/plain text toggle — all persistent across pages and visits.
Unified Cockpit Stack
Every console in the fleet reads the same from the top down — chronometer, banner, nav, wire, dial — so nothing's ever where you didn't expect it, deck to deck.A standard header stack (date/time bar → banner → nav → SQUAD NET ticker → colour dial) on every squad-facing page, Flight Rig included, so layout stays consistent across the board.
Nav-to-Clipboard Bridge
Tap a system on the deck tablet and it lands on the cockpit PC's clipboard, ready to paste into the galaxy map.The board's copy-system button routes through the plugin to your own PC clipboard (per-pilot), so a tablet/phone tap reaches the game. Fire tablet → Windows verified.
Installable Flight Deck
Pin the board to the tablet like a native app — full-screen, one tap, no browser chrome.Progressive Web App: install the board to a Fire tablet, phone or desktop home screen (standalone display, squad-emblem icons).
02
The Build Registry
Builds, carriers & lifecycle · flight-proven
Squadron Build List
One shared manifest of cohort builds. Pick a build and every console in the fleet shows the same picture.Shared KV-backed build list behind the picker on every page.
Auto-Registration on Landing
Set down at a construction ship with the Registrar relay running and the build walks itself onto the board. No forms, no comms.The Blades Registrar EDMC plugin detects construction-ship dockings and posts the build to the registry automatically. Verified end-to-end.
Build Lifecycle
Builds move from the active line to the honors list when the last tonne lands. Proven the night Moy Engineering Silo went operational.Active vs completed grouping driven by RavenColonial's completion flag — verified live with the Moy build.
Completion Stamping
Finished builds are filed once and remembered — the board stops pestering the fleet net about ships that already flew.First sight of a completed build stamps completion (and architect) into the registry so archived builds skip live lookups.
Standing-Down State + Honors Board
When no build is active the board stands down with dignity — and posts the roll of completed constructions instead of pretending a finished site still needs cargo.With zero active builds the dashboard shows an idle state plus recent completions (name, system, architect, date, tonnage).
Self-Updating Board
The board watches the wire and redraws itself when something actually changes — no more hammering refresh to see a build land or complete. Come back to the tab and it catches up on the spot.Change-detected polling (~60s while visible, instant catch-up on tab return) re-renders on real changes only, using RavenColonial eTags and registry diffs.
Career Service Record
Your dossier now reads across every build the cohort has touched: career tonnage, builds contributed, and your line in each build's log.MY STATS aggregates tracked hauls across all registry builds with a per-build breakdown and selected-build highlight. Only uplink-tracked deliveries count — the page says so when totals fall short.
Fleet Carrier Watch
Linked carriers show on the board with their sell manifests — mobile stockpiles in the cohort's pocket.Carriers linked to the build in RavenColonial are listed with their sell counts.
Carrier Identity & Affiliation
Every carrier linked to a build named and badged — ours flying squadron colours, outsiders flagged as unaffiliated.Linked carriers show name + call sign, matched by market ID against the squad carrier registry: squad-owned carriers show their owner, the rest are tagged unaffiliated. In shakedown.
Squad Carrier Link
Park a carrier beside a build and call it in from the cockpit — the fleet watches the mobile depot appear, tops it off while it sits, then jumps the whole haul to the construction site.A pilot links their own fleet carrier to the build they're viewing, straight from the commander deck; the Registrar reads carrier ownership from CarrierStats (live + on the launch backfill) and the board relays the link to RavenColonial, which renders it as a mobile depot. Built end-to-end; awaiting live shakedown with a real carrier.
Station-Type Override
When the papers say only 'construction site', the quartermaster writes in the real class by hand — Large Industrial, Gia pattern — and every deck reads it true.Admins set a build's real facility type from the console; the board shows it in place of the generic 'Colonisation Construction Site' label. Verified live (Gorbenenko Manufacturing). Hand-set for now — auto-inference is on the drawing board.

Attribution & Claims
Architect intelligence · fitted, awaiting shakedown
Claims Ledger
The moment a Blade pays for a system claim, the ledger hears it. From that second, the fleet knows whose name goes on the plaque.The plugin reports ColonisationSystemClaim events (which only fire on the architect's own machine) to a squad claims ledger — first-party architect proof.
Journal Backfill
First light on the new relay, it reads your old flight recorder and files every claim you ever made. History, recovered.On first launch the plugin scans local journal history and reports all past claims — pre-plugin systems get attributed retroactively.
Auto-Create with Attribution
Land at an unregistered site and — after a courtesy grace period — the board cuts the build's papers itself, architect name already on them: ledger first, Raven records second, squad colours as the fallback.Safeguarded auto-create of missing RavenColonial builds, with architect resolved claims-ledger → Raven sibling builds → squad fallback (flagged unverified).
Architect Display
Known architects show on the board, pulled from the fleet's shared records.Architect names read from RavenColonial project records and stored with each registry build.
Claim Hot List
The clock is always running on a fresh claim — the net calls out the ones burning down before the primary port is laid.Claims still inside their ~4-week primary-port window with no build yet ride the SQUAD NET ticker first — red under three days, amber under seven. Cached so it stays cheap as the board fills. Awaiting live shakedown.
Architect Deck
Every architect's own ready-room — see your claims, their countdowns, and set the record straight without troubling the quartermaster.Self-service deck: bind your CMDR once, then see every system you have claimed with its window countdown, fix a mistyped name, mark a primary you have deployed, or release one you have let go — all scoped to your own claims. Reached from the commander deck. Awaiting live shakedown.
04
The Registrar Relay
Self-updating plugin + test-pilot program · newly fitted
Self-Updating Registrar
The relay patches itself in the dark — pulls the new build, checks the seal, swaps it clean, and flies it the moment EDMC comes back up. No reinstall, no zip-hunting.The Blades Registrar plugin auto-updates in place: host-pinned download, SHA-256 verified, atomic swap, applied on the next EDMC restart. Verified end-to-end.
Version Heartbeat
Every relay calls its build number home on a quiet loop, so the board always knows who's current and who's a build behind.The plugin reports its running version to the board on a heartbeat; drives the restart blare and the roster's per-pilot version readout.
Beta Channel & Test Pilots
A shakedown crew flies the next build first. Betas reach only the pilots cleared for them; the fleet stays on proven kit until the crew signs off. Pull a pilot's ticket and the relay walks them back to the line build.Role-gated release channels: test pilots receive beta builds (any version carrying a letter), everyone else stays stable. Revoking test-pilot status auto-downgrades that pilot back to the stable build. Verified live.
RESTART-EDMC Blare
A relay a build behind and the SQUAD NET wire sounds off — tag, border and the words RESTART EDMC pulsing amber-to-fleet — and it won't quit until the new build reports in. No relay at all? COMPLETE SETUP instead.Ticker takeover on every member page blares RESTART EDMC (or COMPLETE SETUP for pre-2.0 / no plugin) until the heartbeat reports the target version, then clears itself. Only the tag, border and keyword flash, so the message stays readable. Verified live.
Roles Console
The quartermaster's crew sheet — grant a pilot their shakedown ticket from a dropdown of the whole roster, take it back with a click.Admin ROLES card assigns test-pilot (and other) roles per commander from a member dropdown; multi-role supported; changes take on the pilot's next heartbeat, and a revoke pushes them back to stable.
One-Click Release Cut
Ship the build and the console reads its own papers — version and notes lifted straight from the deployed relay — one button cuts it to the whole fleet or just the shakedown crew.Admin REGISTRAR RELEASE card auto-fills version + suggested notes from the deployed zip's load.py; one click cuts stable (all pilots) or beta (test pilots), SHA-256 hashed. A letter in the version = beta.
Shakedown Checklist
Cleared for shakedown? A ⚑ TEST PILOT chip lights your deck and opens the flight card — what to fly, what to watch, and a switch to sign each item back to the fleet.Test pilots see a ⚑ TEST PILOT chip (gated on real role) linking a shakedown checklist; a Submit reports which items tested good, and confirmed items pre-mark in future checklists.

Admin Console + Backup
A command deck behind a locked hatch — the fleet's quartermaster reads the ledger, corrects a mis-filed plaque, waves a new Blade through the airlock, and takes the whole record home in a strongbox. Lockout-proof (owner is permanent). Live-verified end-to-end.

Admiral role is Desk-only; full admin stays separate.
Squad Access
The airlock roster — an admin waves a new Blade through the perimeter with a single email, or seals it behind them, without ever touching the station's core systems.Admins grant or revoke squadmate site logins straight onto the Cloudflare Access policy from the console — recruits sign in at once by email OTP. Owner & admins are protected from removal. Live-verified.
Squad Broadcast
Four channels on the fleet wire the quartermaster works by hand — galactic headlines, the standing community goal, and two open frequencies for squad word. Old news burns off on a timer so the band never goes stale.Admin-editable ticker slots (GalNet summary, Community Goals, two free-form) with per-slot auto-expiry, scrolling in SQUAD NET across every page. Paste AI summaries; set an expiry and stale news clears itself.
Uplink Field Manual
The five-stage provisioning guide you are standing in, plus the squad-only Registrar download.Setup guide with staged instructions and the gated plugin zip download.
